01 · What it is

Decanter is a native Mac app that runs Windows games and programs, an open-source alternative to CrossOver. It sets up Wine, Apple's Game Porting Toolkit and the DirectX translation layers for you, then gets out of the way.

Each game lives in a bottle: a self-contained Windows install with its own settings, so one game's fixes never break another.

02 · Features

  • One-click Steam, Epic, GOG Galaxy, Battle.net, EA app and Ubisoft Connect
  • Visual C++, .NET, DirectX 9, PhysX and more via Winetricks
  • Library with real Windows icons; add any game to Launchpad, Spotlight and the Dock
  • Open .exe / .msi files straight from Finder
  • Per-bottle Windows version, Retina mode, AVX, ESync, DLSS → MetalFX
  • DLL overrides, environment variables, logs, winecfg and regedit built in

03 · Graphics backends

D3DMetalDirectX 11 / 12 → Metal (Apple GPTK)
DXMTDirectX 10 / 11 → Metal
DXVKDirectX 10 / 11 → Vulkan → Metal (MoltenVK)
WineD3DDirectX 1–9, OpenGL

04 · Install

  1. Download the .dmg and drag Decanter to Applications.
  2. First launch: right-click → Open (the app isn't notarized yet).
  3. Decanter installs Rosetta if needed and downloads the engines (~470 MB).
  4. Create a bottle, install Steam, play.

05 · Limits

Online games with kernel or Windows-only anti-cheat (Easy Anti-Cheat, BattlEye, Vanguard), such as Rocket League, Valorant or Fortnite, won't run. Use GeForce NOW or a Windows PC for those.
